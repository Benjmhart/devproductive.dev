# Ben Hart

I'm a software developer in Toronto and the CTO of [MLabs](https://mlabs.city), a Haskell and Rust consultancy. I've
written Haskell and PureScript for most of my career, and more Rust lately.

This site is about developer productivity on Linux: a keyboard-driven desktop (XMonad), terminal tools, and running
coding agents on several machines at once. New posts are on the [blog](/blog/) and in the [feed](/atom.xml).

## Projects

- [keybind-find](https://github.com/Benjmhart/keybind-find): press one hotkey and get a searchable list of the
  shortcuts that work in the window you're in, read from your real configs; pick one and it presses the keys for you.
  Reads about 40 programs: window managers, terminals, editors, file managers.
- Plugins for [herdr](https://herdr.dev), a terminal multiplexer for coding agents:
  - [herdr-queues](https://github.com/Benjmhart/herdr-queues): the agents waiting on you, on every machine, in your
    own queues; Enter jumps there.
  - [herdr-inandout](https://github.com/Benjmhart/herdr-inandout): vim's jump list (back and forward) across every
    machine herdr reaches.
  - [herdr-machine-icons](https://github.com/Benjmhart/herdr-machine-icons): one icon per machine in herdr's sidebar.
- Older: [purehmr](https://github.com/Benjmhart/purehmr) (hot module replacement for PureScript with spago),
  [iosevka-palooza](https://github.com/Benjmhart/iosevka-palooza) (Iosevka with ligatures for JavaScript and Haskell).
